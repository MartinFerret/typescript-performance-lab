Lab #002Open question

TypeScript 6 vs 7 on type-fest

3.5×faster check of the sources, TypeScript 7 vs 6

Being re-measured

Most of the gain comes from the native compiler, so expect it even on small CI runners. The default mode does not use all available cores: on this 12-core machine, --checkers 8 checked the sources in 0.377 s, 22% faster than the default mode (0.484 s), and --checkers 4 took 0.475 s.

Typed events: the elegant type that slowed down every call site

−57%check time with TypeScript 7 after the fix

A mapped type with an as clause is evaluated backwards at each indexed call site. If you can infer the key from a generic instead, the checker does far less work.

Method

How every experiment works

Same protocol each time, so results can be compared and reproduced on any machine.

  1. Step 1

    One question

    A single hypothesis, written before measuring.

  2. Step 2

    Pinned versions

    Compilers, target project commit and machine are recorded with every result.

  3. Step 3

    Same measurement

    tsc --extendedDiagnostics, several runs per condition, median reported with the range.

  4. Step 4

    One change at a time

    Type safety proven with tests that must still fail to compile.
